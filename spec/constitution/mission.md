## What

Plug-and-play skills that change how AI coding agents work: senior engineering habits, safe
automation and small productivity tools, installable and updatable with one command.

## For whom

Marcos first, so all his projects follow the same pattern; then any developer who wants their
agent to work like a pragmatic senior engineer, without configuring it from scratch.

## Why now

Agents write a lot of code fast. Without built-in habits (specs, reviews, security, versioning),
that speed turns into unmaintainable projects.

## What it is not

- Not a framework or a generic prompt collection.
- No telemetry, no hidden network calls.
- Not tied to one agent forever (portability is planned: SPEC-0013).

## Success looks like

- Install and update in one command (`/plugin`).
- Marcos's projects share one Spec-Driven Development pattern.
- Others install the skills and they hold up.
